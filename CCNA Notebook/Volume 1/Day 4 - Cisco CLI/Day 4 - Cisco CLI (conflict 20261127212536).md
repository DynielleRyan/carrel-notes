
Cisco CLI has 3 modes.

- User Exec Mode  indicated by a > 
- Privileged Exec Mode Indicated by a # (en/enable)
- Global Configuration mode Indicated by a (config) # (configure terminal/ con f)
 - hostname


Cisco IOS devices makes use of two different text files that stores the device's configuration: running-config and startup-config.

- View each configuration file (show running-config), (show startup-config)

To save changes made to the running-config file, the contents must be copied to startup-config file, otherwise, the device will have a factory-default configuration every time it boots up.

Factory-default - refers to the original state of the device as it is sent from the factory, before any configuration changes are made.
